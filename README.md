# 📸 QR Photo Finder

### AI-Powered Smart Event Photo Retrieval System

> An intelligent event photography platform that helps users instantly discover their photos using facial recognition and selfie-based image matching.

---

## 📖 About the Project

QR Photo Finder is an AI-powered event photo retrieval platform designed to help users **instantly discover their photos from large event galleries using facial recognition and image matching technologies**.

During large events, hundreds or thousands of photographs may be captured. Manually searching through the entire event gallery to identify personal photos can be time-consuming and inefficient.

QR Photo Finder solves this problem using an intelligent **selfie-based photo search system**.

Users scan an event QR code and upload a selfie. The system analyzes the uploaded image using **Computer Vision and Facial Recognition technologies**.

The AI system then searches the event gallery, identifies photographs containing the same person, and automatically retrieves matching images.

Users can quickly view and download their identified photographs without manually searching through the complete event gallery.

---

## 💡 Why QR Photo Finder?

Finding personal photographs from large event galleries can be difficult, especially when thousands of images are captured during conferences, college events, weddings, and public gatherings.

QR Photo Finder automates this process using Artificial Intelligence.

The system focuses on:

- Eliminating manual photo searching
- Providing selfie-based photo discovery
- Using facial recognition for intelligent matching
- Searching large event galleries automatically
- Reducing photo discovery time
- Providing quick access to matching photographs
- Improving the event photography experience
